## 2.5 Ultrasonic installation

Please note that ultrasonic waves are driven by a servo and achieve a 180 degree rotation, so the servo angle needs to be set, otherwise the servo will not function properly.

**Arduino code：**

Please note that uploading code requires adding the rudder hangar file first!!! For details, please refer to the Arduino tutorial section `3.6 Servo Control`

```c
#include <ESP32Servo.h>  // Include the ESP32 servo control library

Servo myServo;           // Create a servo object named myServo

// Define the pin connected to the servo signal line as GPIO42 (please modify according to actual wiring)
const int SERVO_PIN = 42; 

void setup() {
  // Initialize the servo
  myServo.attach(SERVO_PIN);
  myServo.write(90);        // Initialize the servo angle to 90 degrees
  delay(1000);              // Wait for 1000 milliseconds (1 second) for the servo to stabilize
}

void loop() {
}
```

**MicroPython code：**

Please note that uploading the code requires adding the ESP32S3_4WD_Car library file first!!! For details, please refer to MicroPython tutorial `4.6 Servo Control`

```python
# Take out a "magic box" (control module) named Keyes_ESP32S3_4WD from the "Car/Robot" toolkit provided by the manufacturer
from ESP32S3_4WD_Car import Keyes_ESP32S3_4WD
# Import the "time" toolkit, because we need the program to "wait" and control the rhythm of time
import time

# Assign a "house number" (pin number) to the servo's signal wire. Here we choose pin 42
SERVO_PIN = 42

# Open the "magic box" just taken out and create a control object named servo
servo = Keyes_ESP32S3_4WD()

# Tell the magic box: "Please initialize (prepare) pin 42, we are going to start controlling the servo!"
servo.Servo_init(SERVO_PIN)

# Issue the first command: make the servo rotate to 90 degrees (the exact middle position) first
servo.Servo_set_angle(90)
# Pause the program for 1 second, giving the servo a little time to slowly rotate to 90 degrees and stand firmly
time.sleep(1)
```
